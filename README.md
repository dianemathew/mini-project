SOCIAL MEDIA CHURN PREDICTION

Project Description:
This project predicts whether a social media user is likely to churn based on their social media activity and engagement behaviour.

Project Topic:
 Social Media User Churn Prediction Using Machine Learning

Project Description:
Social media platforms rely on user engagement and retention to maintain an active user base. Identifying users who are likely to stop using a platform can help improve user retention and engagement strategies.

This project uses machine learning classification techniques to predict whether a social media user is likely to churn based on their activity patterns and engagement behaviour. The model analyses user-related features, such as session activity, interactions, watch time, and engagement scores, to identify potential churn.

The project also includes a Flask-based web application that allows users to interact with the trained machine learning model through a simple interface.

Machine Learning Task:
Classification

Dataset Name: Meta-Style User Dataset
Source: Kaggle
